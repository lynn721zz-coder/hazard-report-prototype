# HSE 管理系统 · 隐患分析报告原型（v2.0）

中国中化 HSE 管理系统中「隐患分析报告」模块的交互原型，单文件 HTML 实现，无外部依赖。

## 在线预览

GitHub Pages：<https://lynn721zz-coder.github.io/hazard-report-prototype/>

## 功能范围

- **系统框架**：顶栏（中国中化）、监督侧菜单树、多页签
- **隐患分析报告**：周期定时报告 + AI 辅助分析报告两级列表，报告详情（指标卡 / 隐患类型卡片 / 反馈聚合看板）
- **反馈体系（两级）**：
  - 报告级：列表页对单份报告 点赞 / 点踩 / 意见
  - 类型级：详情页对每个隐患类型 点赞 / 点踩 / 意见（含问题标签）
- **反馈统计看板**：点赞/点踩/意见汇总指标、Top6 对象分布、明细筛选、CSV 导出
- **报告生成配置**：生成周期多选组合（每周/每月/每季度/自定义规则，支持每年固定日期与下次执行提示）、关注类型标签可新增/移除、修订记录（表格列表）
- **查询**：时间范围、所属单位、隐患类型模糊查询与条件清除

## 说明

- 纯前端原型，数据为演示用模拟数据，反馈与配置仅保存在内存中
- 隐患类型数据源自真实隐患分析报告语义归类示例
